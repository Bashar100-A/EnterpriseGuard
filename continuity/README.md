# EnterpriseGuard ADIE — Continuity Folder

This folder contains the permanent reference files that allow a fresh
session to recover the project's memory without relying on conversation
history.

## Reading Order

1. `RULES.md` — binding operational and security rules
2. `CURRENT_STATE.md` — latest checkpoint and next actions
3. `COMPONENTS.md` — component inventory and progress
4. `DECISIONS_INDEX.md` — quick index of governance decisions
5. `GLOSSARY.md` — unified terminology
6. `IDEAS_BACKLOG.md` — deferred and future ideas
7. `LESSONS_LEARNED.md` — mistakes and lessons

## Rules

- These files are written and updated manually by the owner.
- They are never generated by Qwen.
- They summarize and reference, not duplicate full content.
- Dynamic files such as `CURRENT_STATE.md` are excluded from integrity monitoring.
- `RULES.md` is the backbone and must be read first.
